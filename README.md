# Creative Manager Public

GitHub Pages でそのまま公開できる、クリエイティブ管理アプリの静的版です。

## 含まれる機能
- ダッシュボード
- 受注管理
- 新規受注登録モーダル
- テンプレート管理
- スタッフ管理
- 日程一覧
- 外注管理
- AI風の納期 / 外注判定
- 通知文 / 外注指示書のダウンロード
- localStorage による簡易保存

## 公開方法
1. このフォルダの中身を GitHub リポジトリにアップロード
2. GitHub Pages を `main` / `root` で有効化
3. 数分待つ

## ファイル
- index.html
- style.css
- app.js
