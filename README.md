# デザインマネージャー 公開用4ファイル版

このZIPは GitHub Pages にそのまま上書きできる静的版です。

## 入っているファイル
- index.html
- style.css
- app.js
- README.md

## 今回入っている機能
- パソコン / スマホ 表示切り替え
- PDF読込による受注下書き
- サンプル1件追加（30件プール）
- 受注総額 / 今月受注額 / 表示中合計 / 外注候補金額
- スタッフ追加・編集・削除
- 稼働時間の自動算出
- 日程ページのカレンダー表示
- 外注完了案件の受信登録
- LINE通知文コピー

## GitHub Pages 反映手順
1. ZIPを解凍
2. GitHub の `creative-manager-app` を開く
3. 次の4ファイルを上書き
   - index.html
   - style.css
   - app.js
   - README.md
4. Commit changes
5. 公開URLを開いて Ctrl + F5 で更新
